## 0.29.0 桌面版内核重写：本地服务内置 + 数据落到本机真实文件

这一版把桌面版的骨架换了：**上游模型请求、内容解析、媒体处理和本地存储全部搬进主进程里自带的本地服务**，
渲染层只保留 UI 和状态机。应用启动时随机生成一次性 token，只有本机的渲染窗口能用这个服务。

### 架构：本地业务服务随应用一起启动

+ 服务固定监听 `127.0.0.1:23212`，与渲染页面（`127.0.0.1:23211`）分开。
+ `/api/*` 与 `/files/*` 每次启动都会校验随机 token：渲染层通过 preload 桥拿 token，
  浏览器直连（开发模式、Docker）走的是另一套地址，不受影响。
+ `/health` 不校验，方便看服务是否活着；媒体发布通道 `/__media/*` 也不校验（设计如此，只在本机回环监听）。
+ 服务万一启动失败，主进程会记日志并弹窗提示「本地服务启动失败 / 应用将以受限模式打开」，不会直接白屏。

### 数据：从浏览器 IndexedDB 改为本机真实文件

+ 画布项目、「我的素材」、生成记录等全部写到用户目录下的真实文件（`<用户目录>/data/`），
  不再是浏览器里那堆 IndexedDB 分片。
+ 首次启动一次性把旧的 IndexedDB 数据导入新目录，并留下备份清单；迁移失败时不写标记、不删旧数据。
+ 本地存储的写入做了串行化，避免并发写坏文件。
+ 相应地移除了 `canvas-proxy` 转发、浏览器 FFmpeg wasm 和 localforage 运行时存储；
  媒体处理改用随包发布的原生 ffmpeg。

### 素材公网发布

+ 新增 `/__media/upload` 与 `/__media/<文件名>`（支持 Range 分段拉取），随本地服务一起启动，
  供公网隧道回拉本机视频；设置里的「素材公网基址」改指向 23212 端口。

### 工具页收口（沿用上一阶段未发布的改动）

+ 39 个工具页配色改回无限画布风格：暖灰石色底、深石色主按钮、参数选中用橙色；深色主题不再被强制成浅色紫。
+ 商品图改为两步结构，第二步是原站式的全屏编辑器（参考图抽屉、图层、背景调节、保留遮挡物、手动抠图）。
+ 服装套图上传上限改为原站的 16 张；商品套图支持自定义宽高。
+ 按原站前端源码重做 8 个工具：POD 素材、饰品文字、场景迁移、AI试衣XSY、AI姿势生成、上装换料、
  场景裂变链接、商品营销素材。
+ 接上真实能力：商品图视觉分析、营销脚本/提示词 AI 帮写与优化、图片翻译端到端 OCR + 译文回填 + 图层编辑、
  自动主体分割与点选交互抠图、电商商品链接解析与 A+ 长图切分、视频固定时长拼接、跨工具结果接力与批量生图矩阵。
+ 主操作按钮全部调整到首屏可见（此前有 9 个工具的按钮要滚很久才能点到）。

### 修复

+ 补齐图片文字编辑缺失的 OCR 识别翻译模块（此前该页面调用一个不存在的模块），
  并修正图片文字编辑、智能扩图的 AI 文案调用参数。
+ 修复商品图（替换背景）与图转视频两个工具页在渲染期读取未初始化变量，导致**整页报错白屏**的问题。
+ 修复刷新后只剩 `storageKey` 的历史结果会优先使用失效的 `blob:` 地址导致结果图裂，现按本地媒体字节重新水合。
+ 修复 AI穿戴的历史记录只能看不能回填、印花提取任务刷新后丢历史。
