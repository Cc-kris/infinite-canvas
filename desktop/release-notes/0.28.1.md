## 0.28.1 画布底部工具条补上「固定图片」入口

0.27.0 加的「固定图片」节点，之前只能从创建菜单（双击空白处、或从节点拖线后选「固定图片」）
进来，底部工具条里那一排「文本 / 图片 / 视频 / 音频」却漏了它——想放一个固定工作位，
得先想起菜单，不像其他节点那样抬手就有。

这一版把按钮补在「图片」右边，图标与文案跟随中英文界面切换；点一下就在视野中央
创建一个空的固定图片节点（生成设置照旧：默认渠道、自动比例、3 张）。

实测：点按钮后画布立即出现固定图片节点，左侧元素计数 +1，节点内容为「空图片节点 /
描述要生成的图片内容 / gpt-image-2（默认渠道）/ 自动 · 1:1 · 3 张」。
