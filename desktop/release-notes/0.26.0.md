## 0.26.0 新增：三种 Agent 都能手选安装目录；修好 Claude Code 模型列表

**一、Agent 装在哪儿，你说了算**

以前三种 Agent 只在固定的默认位置找可执行文件。装在别处——D 盘、绿色版、
自己解压的便携版、WSL 里映射出来的目录——桌面版就只会说「未安装」，
没有任何补救入口。这次把这条路补上了：

- 卡片上没扫到 Agent 时，下面直接出现一行「选择目录」；
- 点它会弹系统目录选择框，选定后**立刻在该目录里递归查找**可执行文件
  （多层子目录也找得到），命中就写进配置并显示找到的路径与版本，可以直接连接；
- 也可以手填路径再点「扫描」；
- 想改回默认位置，点「清除」即可，下次仍按默认位置扫描。

配置记在 `canvas-agent.json` 的 `agentPaths` 里，重装应用、重启服务都不会丢。
Claude Code、Codex、Galley 三者一视同仁。

**二、连上 Claude Code 后模型列表是空的**

这个的根因在缓存：前端先问「当前是什么运行时」，再据此决定请求
`/agent/models` 还是 `/agent/codex/models`。那次询问一旦失败，会把结论
兜底成 codex **并缓存下来**——于是 Claude / Galley 下也去请求 codex 的接口，
必然失败，模型列表就一直空着，而且怎么重连都不好。

现在模型清单统一走 `/agent/models`：它按后端当前的运行时返回对应清单，
并在响应里带上运行时本身。前端直接采用响应里的值，失败也不再落缓存。
实测连上 Claude Code，模型选择器显示「Claude Code 模型」，选项是
默认模型 / Claude Sonnet / Opus / Haiku；输入框提示、权限模式、思考程度
也都跟着运行时走。
