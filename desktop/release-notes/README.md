# 桌面版更新说明（一版一文件）

- 文件名 = 版本号：`desktop/release-notes/<版本>.md`，例如 `0.26.0.md`。
- **每个文件只写「这个版本自己改了什么」**，不要累积往期版本的内容——往期版本有自己的文件，
  Release 页面也会各自展示，堆在一起会让用户以为新版本改了一堆旧东西。
- 发版前先新建 `desktop/release-notes/<新版本>.md`；CI 发布 job 按 tag（`desktop-vX.Y.Z`）取
  同名文件作为 GitHub Release 正文，找不到文件会直接失败（不会退回「发全量说明」）。
- `_install.md` 是共用的安装步骤，CI 会把它接在每个版本正文后面，改一次对所有版本生效。
- 应用内更新弹窗读的是仓库根的 `CHANGELOG.md`（也是按版本分节），发版时两处都要写。
