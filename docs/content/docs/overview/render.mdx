# Deploy on Render

> **Legacy browser deployment.** This branch ships the desktop client only. The web build is frozen on `feat/linkfox-v1-real`; this page is kept for reference and is not guaranteed to work.

[Deploy to Render](https://render.com/deploy?repo=https://github.com/Cc-kris/infinite-canvas)

1. Select **Deploy to Render**.
2. Sign in and connect GitHub as prompted.
3. Confirm the deployment.

When deployment finishes, open the assigned `.onrender.com` domain.

The default configuration uses Render's free Web Service. It sleeps after a period of inactivity and wakes on the next request. In the browser build, application data is stored in the browser and prompt repositories are fetched by the frontend. The free tier is suitable for evaluation and demos; use Vercel or configure WebDAV for longer-term use.
