# 快速开始

本分支只发布桌面客户端。渲染层负责界面，Electron 主进程启动本地业务服务，由它请求模型接口、处理媒体并保存数据。

## 安装包

安装包发布在 [Releases](https://github.com/Cc-kris/infinite-canvas/releases) 页面。macOS / Windows 均为未签名包，首次打开需按发布说明手动放行。

## 本地构建运行

需要 Node.js 20+ 与 pnpm。

```bash
git clone git@github.com:Cc-kris/infinite-canvas.git
cd infinite-canvas
pnpm --dir web install
pnpm --dir desktop install
pnpm --dir web build
pnpm --dir desktop start
```

窗口从 `http://127.0.0.1:23211` 加载 `web/dist`，业务服务在 `http://127.0.0.1:23212`。修改前端后需重新构建并重启，当前没有前端热更新。

## 打包安装包

```bash
pnpm --dir desktop dist:mac
pnpm --dir desktop dist:win
```

命令会先构建 Agent、本地服务与前端。ffmpeg 只打包当前构建机架构，跨架构需在对应机器或 CI 上执行。

## 首次使用建议

- 先打开右上角配置弹窗，填入自己的 `Base URL`、`API Key` 和模型名。
- `/prompts` 会经本地服务拉取提示词仓库，并保存到用户目录。
- 只有需要跨设备同步画布、素材和生成记录时，才需要在配置弹窗中填写 WebDAV。

## 数据位置

画布工程、我的素材、草稿、日志与插件都以文件形式保存在 `<userData>/data/`（macOS 为 `~/Library/Application Support/Infinite Canvas/data`）。AI API Key 也保存在本机，但请求由主进程发出，页面不直连上游；这里仍是本地数据，项目没有云同步。

## 浏览器版历史部署

Vercel、Docker、Render 是浏览器版的历史部署方式，仅保留文档参考，本分支不再支持。网页版代码冻结在 `feat/linkfox-v1-real`。
