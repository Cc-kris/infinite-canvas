# Sponsor the Project

This project is a derivative work of [basketikun/infinite-canvas](https://github.com/basketikun/infinite-canvas), maintained in this repository. If it is useful to you, a star — or using the sponsor below — is the most direct way to support it.

## Sponsor

### CCAI (cc-ai.xyz)

[CCAI](https://cc-ai.xyz) is an LLM aggregation platform for developers. It is OpenAI-compatible, so a single API key gives you access to models from multiple providers, billed by usage.

It works out of the box with Infinite Canvas: open the settings in the top-right corner, set `Base URL` to `https://cc-ai.xyz/v1`, paste a key from [cc-ai.xyz](https://cc-ai.xyz), and you can start generating images and chatting.

## Other ways to help

- Star [this repository](https://github.com/Cc-kris/infinite-canvas).
- Open issues to report problems, improve the docs, or suggest changes.
- Send pull requests (changes and test results are reviewed before merging).

## Sponsorship

Only AI tools, model services, and API services are accepted as sponsors at the moment; placement and copy are decided by the maintainer. Open an issue in this repository if you are interested.
