# 赞助支持

本项目由 [basketikun/infinite-canvas](https://github.com/basketikun/infinite-canvas) 二次开发而来，当前维护工作由本仓库维护者承担。如果你觉得项目有用，点个 Star、用一下赞助商的服务，就是最直接的支持。

## 赞助商

### CCAI（cc-ai.xyz）

[CCAI](https://cc-ai.xyz) 是一个面向开发者的大模型聚合平台，兼容 OpenAI 协议，一个 API Key 即可调用多家主流模型，按量计费。

在无限画布中直接可用：打开右上角配置，把 `Base URL` 填成 `https://cc-ai.xyz/v1`，再填入在 [cc-ai.xyz](https://cc-ai.xyz) 申请的 Key 即可开始生图与对话，不需要自建中转服务。

## 其他支持方式

- 给[本仓库](https://github.com/Cc-kris/infinite-canvas)点 Star。
- 提交 Issue 反馈问题、补充文档或提出改进建议。
- 提交 PR（合并前会先说明改动内容与测试结果）。

## 赞助合作

本项目目前仅接受与 AI 工具、模型服务、API 服务相关的赞助投放，展示位置与文案由维护者评估后确定。有合作意向请在本仓库开 Issue 联系。
