## 2. 统一改法（每页 3 步）

**第 1 步 换列布局**：把页面根部的自写 grid（`grid ... lg:grid-cols-[...]`、`xl:grid-cols-[...]`）整体换成 `ToolWorkspaceColumns`，配置栏进 `config`，结果/画布进 children。删掉原来手写的 `minmax(0,420px)`、`340px`、`998px` 之类列宽。

```tsx
// 参考实现：web/src/components/tools/workspaces/crop.tsx（已验收 PASS，cfg=420 main=866 67%）
// 唯一列布局组件 API：web/src/components/tools/tool-workspace-columns.tsx
<ToolWorkspaceColumns
    canvas            // 画布类工具才加（mask/outpaint/crop/designer），配置栏上限放宽到 420
    configSide="left" // 配置在左；原站画布在左、设置在右的页面用 "right"
    className="min-h-0 flex-1 overflow-y-auto p-4"
    config={ <section aria-label="配置区">…原有控件…</section> }
>
    <section aria-label="结果区">…原有画布/结果…</section>
</ToolWorkspaceColumns>
```

**顺序问题靠 DOM 顺序解决，不要写 `order-*`，也不要在模板里拼变量**（Tailwind 扫不到动态类名，会导致两列退化成单列全宽——已实测踩坑）。

**第 2 步 删禁用内容**：页面里 `<WatermarkGroupPanel />` 及其 import 直接删除（PRD 未要求，39 页均不得出现「水印分组」）；出现的「算力」「点/张」「积分」「会员」「免责声明」「促销」「折」「余额」「免费领取」等文案，连同包裹它的徽标/横幅 DOM 一并删除，不要只把字改成别的。

**第 3 步 对齐区域顺序**：按下面每页「区域顺序」逐条核对，缺区域就补，顺序错的就调。**不许把页面退化成「上传框 + 提示词 + 生成按钮」三段式**。
