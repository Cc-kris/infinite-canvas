## 1280×781（命中 81/89，差异均在右侧簇 x）

原站在 1280 下**自身横向溢出**：header 宽 1280，但用户区首个元素 x=1283（用户名左边缘
1283 > 视口 1280），即原站 1280 时右侧用户区被裁掉约 99px。
本地改为在该宽度下**完整可见**（用户名 x=1183），属有意偏离：不复刻原站的裁切缺陷。
其余 81 项（促销条、顶栏、侧栏、主区、导航、胶囊内部几何与配色）全部一致。
