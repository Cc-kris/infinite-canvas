## 7. 新发现的问题（只记录，未改代码）

1. **重复「存入资产」会产生重复资产条目**：本任务已有 15:08 入库的一条，本轮 16:30 再入库生成第二条同标题条目。
   根因：该入口写入的资产 `metadata` **不含 `resultAssetKey`**（`result-assets.ts` 的去重键为
   `tool-result:${toolId}:${taskId}:${itemId}`），因此 `findAssetByKey` 查不到既有条目 → 每次都新建。
   建议（未实施）：SALE_VIDEO 结果入库走 `result-assets.ts` 统一实现，或补写 `metadata.resultAssetKey`。
2. **资产/画布记录的宽高是 1280×720 且无 durationMs**：真实视频是 768×768 / 6.583 s。
   根因：`src/services/media-metadata.ts` 的 `FALLBACK_VIDEO_WIDTH = 1280` —— 探测失败（本环境隐藏标签无法加载视频元数据）时回退默认值。
   即隐藏标签环境下元数据丢失，落到资产库/画布的是回退值；前台正常可见标签里应能探测到真实值（本轮受环境限制未能验证）。
3. 隐藏标签下媒体不加载属 Chromium 行为，非产品缺陷；但由此产生的「封面 img 无 src」会让资产卡在后台标签里没有缩略图。
