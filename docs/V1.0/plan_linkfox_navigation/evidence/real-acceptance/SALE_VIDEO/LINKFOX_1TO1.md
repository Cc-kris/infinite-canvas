## 2. 控件级差异（有意为之 vs 需关注）

| 项 | 原站 | 本地 | 类型 |
|----|------|------|------|
| 视频模型 | `Seedance 2.0 fast`（+「适合日常稳妥出片」副文案） | `grok-imagine-video（ccai-tmp）`，副文案「适合日常稳妥出片」保留 | 有意：模型取本地通道；副文案沿用 |
| 算力消耗 | 显示算力数（如 1190） | 不显示 | 有意（spec 实现边界） |
| 提交按钮 | 「立即生成 + 算力」 | 「立即生成」+「1 条 · 5 秒 · 720P」 | 有意替换 |
| 作品选择 / 商品库选择 | 有（图/视频素材库入口） | 仅本地上传，无「作品选择/商品库选择」 | **差异（已知边界）**：本地以资产库统一承载，见 §3 |
| 生成结果对比（VideoResultCompare） | 原站为成片预览 | 片列表 + 下载/保存资产/发送画布 + 失败态诊断码 | 结构化等价，动作见 `RESULT_ACTIONS.md` |

## 3. 与原站的信息架构等价性结论

- 输入 → 配置 → 生成 → 结果的四段式与原站一致，字段顺序一致（商品图 → 提示词 → 国家语言 → 模型分辨率 → 时长比例 → 结果）。
- 三个"原站有、本地无"的点：**作品选择/商品库选择入口**、**算力显示**、** Seedance 模型**。前两项是 spec 明确允许的实现边界；第三项取决于本地通道配置。
- 结论：**IA 1:1 通过（允许差异项已登记）**。

## 4. 与提交体的交叉核对（关键，见 `IO_DIFF.md`）

页面顶部徽标与配置区显示「1 条 · 5 秒 · 720P」，配置区选中 720P/5秒/9:16；但同一次提交的请求体为 `seconds=6; size=720x720; ratio=1:1`。
即：**页面声明 ≠ 实际请求参数**。这不是 IA 差异，而是参数绑定缺陷（D1），详见 `IO_DIFF.md`。
