## 3. 等价性结论

- 主操作路径（上传原视频 → 截取 → 参考图 → 需求描述 → 类型/模型 → 生成 → 结果）与原站一致，控件顺序一致。
- 差异集中在「营销/复用类模块（优秀案例、一键做同款、历史记录）」与「通道相关（模型名、算力）」，核心编辑能力 1:1。
- **参考图必填**是唯一会影响用户操作结果的差异，但页面已就地提示，不构成误导。
- 结论：**IA 1:1 通过（允许差异已登记）**。

## 4. 与本轮实测结果的交叉核对

页面按钮旁写「1 条 · 5.2 秒」、截取区间为 0–5.2 秒，请求体 `prompt` 也写「输出：1 条视频，时长约 5.2 秒」，但同一请求参数为 `seconds=6`、`size=720x720`、`ratio=1:1`（源片 1344×768 横屏）→ 输出画幅/时长会与声明不符，详见 `IO_DIFF.md` D1。
