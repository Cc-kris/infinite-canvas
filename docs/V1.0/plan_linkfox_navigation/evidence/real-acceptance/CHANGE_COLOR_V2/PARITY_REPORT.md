## 关键实现提示（回归注意）

- 项目 `styles/globals.css` 存在全局覆盖，**选中态/CTA 文字色与 `ml-auto` 之类的对齐工具类都可能被吃掉**：关键颜色/对齐请用内联 `style`（本次「历史记录」右对齐即靠 `marginLeft: "auto"` 修好）。
- CTA 必须放在 `shrink-0` 的外层容器（内容区 `flex-1 overflow-y-auto`），否则会随内容滚走。
- 提示行（blocked/notice）放在按钮**上方**，保证按钮始终贴底。
