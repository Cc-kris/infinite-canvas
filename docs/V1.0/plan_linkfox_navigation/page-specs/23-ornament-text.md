# 23｜饰品文字 `ORNAMENT_TEXT`

- 分类：商品图设计；目标路由：`/tools/product-design/ornament-text`；页面类型：`text`。
- 目标：生成饰品文字效果。
- 证据级别：`permission_redirect_home`；原站 URL：`https://www.linkfox.com/draw/ornament-text`（本账号被重定向 `https://www.linkfox.com/home`）。
- 证据文件：`../evidence/page-dom-20261028/ORNAMENT_TEXT.json`（2026-10-29 实拍）。
- 路由依据：bundle 菜单表 `label:饰品文字, path:/draw/ornament-text, drawType:P.ORNAMENT_TEXT, betaLabel:{饰品文字}{Beta}, whitelist:!0`；本账号同样被重定向 /home。
- 实现边界：复刻信息架构和操作逻辑，使用无限画布设计令牌、资产、任务和模型服务；不搬 LinkFox 前端代码，不复制算力区。

## 1. 页面区域与布局

饰品文字内容｜字体与字号｜左右定位｜效果预览｜结果。桌面采用工具侧栏 + 页面内容；内容内按上述实际工作区组织，不得替换成统一“上传 + 提示词 + 结果”空壳。配置区保持 320–420px 或按画布工具需要扩展；主要编辑/预览区 `minmax(0,1fr)`；结果区有明确空、生成、成功、失败状态。移动端按“输入/编辑/结果”分步，不压缩画布到不可操作。

## 2. 真实控件与内容

当前账号 `/draw/ornament-text` 重定向首页；字段明确为 prompt、fontname、fontSize、left、right。界面以文字样式编辑和预览为主，不虚构材质库。

## 3. 状态联动与校验

字体/字号变化实时更新文字层；left/right 控制文字在饰品上的相对位置；修改文字只更新预览，生成后保存参数快照。

通用状态必须落到具体字段：`draft/dirty → validating → submitting → running → succeeded|failed|cancelled`；切换配置不删除已完成任务；重新上传源文件时使旧结果标记为“来自旧版本”，不能冒充当前配置结果。

## 4. 主操作路径

输入文字与效果描述→选字体字号→调左右位置→生成→检查字形和贴合→保存。

提交按钮旁显示产物数量/预计输出，不显示原站算力。任务提交后锁定本次配置快照；仍允许编辑下一稿。结果支持下载、保存资产、发送到画布（如适用）、单结果重试和查看本次输入快照。

## 5. 失败与恢复

- 上传失败：保留其他输入和配置，定位到失败文件；格式/尺寸/数量错误在控件旁说明，不只弹通用错误。
- 任务失败：保留源资产、全部配置、蒙版/图层/片段等工作数据；允许按相同快照重试或修改后新建任务。
- 部分失败：按结果单元/语言/SKU/片段显示状态，只重试失败单元，已成功结果不重复生成。
- 离开/刷新：保存当前工具草稿和编辑器状态；有未保存画布工作时弹出确认。网络超时进入 `unknown`，先查询任务再决定是否重试，禁止盲目重复提交。

## 6. UI 组件与视觉

组件：`TextLayerCanvas + FontPropertyPanel + TextBoxList`。面板用 `bg-card`，主区用 `bg-background`，边框 `border-border`，选中 `bg-accent`，主操作 `bg-primary`；正文 14px/22px，控件 36px，主按钮 40px，圆角 8–10px。颜色、字体和焦点环全部取无限画布令牌；不使用 LinkFox 紫色品牌。画布工具必须提供 40×40px 最小点击区、键盘焦点和撤销/重做。

## 7. 技术绑定与数据

- 专用组件：`TextLayerCanvas + FontPropertyPanel + TextBoxList`；共享 ToolShell 只负责导航、资产选择、任务状态和历史，不吞掉本页专用状态。
- 草稿键：`tool-draft:v1:ORNAMENT_TEXT`；任务包含 `toolId + draftRevision + configSnapshot + sourceAssetIds + clientOperationId`。
- 提交前在当前页面执行必填、数量、尺寸、蒙版/位置等校验；服务端按同一 schema 再校验。

## 8. 本页验收

1. 首屏能看到并操作本页独有区域与控件，不是通用任务卡片；上述全部主流程可实际走通。
