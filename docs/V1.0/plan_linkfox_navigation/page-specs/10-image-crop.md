# 10｜图片裁剪 `IMAGE_CROP`

- 分类：智能修图；目标路由：`/tools/smart-edit/image-crop`；页面类型：`crop`。
- 目标：按比例或平台规格裁剪图片。
- 证据级别：`workspace_dom`；原站 URL：`https://www.linkfox.com/draw/image-crop`。
- 实现边界：复刻信息架构和操作逻辑，使用无限画布设计令牌、资产、任务和模型服务；不搬 LinkFox 前端代码，不复制算力区。

## 1. 页面区域与布局

裁剪画布与历史｜尺寸调整｜比例调整｜平台预设｜自定义尺寸。桌面采用工具侧栏 + 页面内容；内容内按上述实际工作区组织，不得替换成统一“上传 + 提示词 + 结果”空壳。配置区保持 320–420px 或按画布工具需要扩展；主要编辑/预览区 `minmax(0,1fr)`；结果区有明确空、生成、成功、失败状态。移动端按“输入/编辑/结果”分步，不压缩画布到不可操作。

## 2. 真实控件与内容

自由裁剪；Amazon 1600²、Walmart 2000²、Etsy 2000²、Temu 1200²、Shopify 方/横/竖、SHEIN 1340×1785 等平台；目标宽/高和保存自定义尺寸；撤销/重做/重置/重新上传/下载。

## 3. 状态联动与校验

选择平台同时写入平台、比例和像素尺寸；手动拖框切为自由裁剪但不删除预设；锁定比例时拖角保持比例；换图重置画布变换；下载使用当前裁剪结果。

通用状态必须落到具体字段：`draft/dirty → validating → submitting → running → succeeded|failed|cancelled`；切换配置不删除已完成任务；重新上传源文件时使旧结果标记为“来自旧版本”，不能冒充当前配置结果。

## 4. 主操作路径

上传→选平台或自由比例→拖动裁剪框→核对目标像素→应用→下载/保存。

提交按钮旁显示产物数量/预计输出，不显示原站算力。任务提交后锁定本次配置快照；仍允许编辑下一稿。结果支持下载、保存资产、发送到画布（如适用）、单结果重试和查看本次输入快照。

## 5. 失败与恢复

- 上传失败：保留其他输入和配置，定位到失败文件；格式/尺寸/数量错误在控件旁说明，不只弹通用错误。
- 任务失败：保留源资产、全部配置、蒙版/图层/片段等工作数据；允许按相同快照重试或修改后新建任务。
- 部分失败：按结果单元/语言/SKU/片段显示状态，只重试失败单元，已成功结果不重复生成。
- 离开/刷新：保存当前工具草稿和编辑器状态；有未保存画布工作时弹出确认。网络超时进入 `unknown`，先查询任务再决定是否重试，禁止盲目重复提交。

## 6. UI 组件与视觉

组件：`CropCanvas + PlatformPresetGrid + PixelSizeForm`。面板用 `bg-card`，主区用 `bg-background`，边框 `border-border`，选中 `bg-accent`，主操作 `bg-primary`；正文 14px/22px，控件 36px，主按钮 40px，圆角 8–10px。颜色、字体和焦点环全部取无限画布令牌；不使用 LinkFox 紫色品牌。画布工具必须提供 40×40px 最小点击区、键盘焦点和撤销/重做。

## 7. 技术绑定与数据

- 专用组件：`CropCanvas + PlatformPresetGrid + PixelSizeForm`；共享 ToolShell 只负责导航、资产选择、任务状态和历史，不吞掉本页专用状态。
- 草稿键：`tool-draft:v1:IMAGE_CROP`；任务包含 `toolId + draftRevision + configSnapshot + sourceAssetIds + clientOperationId`。

## 8. 本页验收

1. 首屏能看到并操作本页独有区域与控件，不是通用任务卡片；上述全部主流程可实际走通。
2. 逐项验证第 3 节联动；源图替换、Tab 切换、数量/语言/比例变化不会串改无关状态。
3. 上传失败、生成失败、部分失败、刷新恢复均按第 5 节执行；结果与提交快照一致。
4. 1920/1440/1024/768/390px 下无关键控件消失；深色模式、键盘操作和移动端主要流程可用。
