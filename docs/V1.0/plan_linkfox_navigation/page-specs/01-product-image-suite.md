# 01｜商品套图 `PRODUCT_IMAGE_SUITE`

- 分类：电商套图；目标路由：`/tools/ecommerce-suite/product-image-suite`；页面类型：`suite`。
- 目标：一张商品图生成多视角白底图与实拍套图。
- 证据级别：`workspace_dom`；原站 URL：`https://www.linkfox.com/draw/product-image-suite`。
- 实现边界：复刻信息架构和操作逻辑，使用无限画布设计令牌、资产、任务和模型服务；不搬 LinkFox 前端代码，不复制算力区。

## 1. 页面区域与布局

商品图上传与 AI 分析｜品牌与合规｜模型/品质｜A+ 图设置｜主副图设置｜整组结果。桌面采用工具侧栏 + 页面内容；内容内按上述实际工作区组织，不得替换成统一“上传 + 提示词 + 结果”空壳。配置区保持 320–420px 或按画布工具需要扩展；主要编辑/预览区 `minmax(0,1fr)`；结果区有明确空、生成、成功、失败状态。移动端按“输入/编辑/结果”分步，不压缩画布到不可操作。

## 2. 真实控件与内容

商品图支持本地上传、作品库、商品库；商品信息 0/2500，AI 分析/向导；品牌基因控制主色和字体风格，合规区选择敏感词库和替换词库；模型 LF G-2.5 Sunburst，1K/2K/4K，低至最大品质；A+ 单选高级/手机/普通/自定比例并设张数和排版；主副图多选卖点/白底/场景/特写/特写白底并分别设张数；比例 1:1、3:4、4:3、2:3、3:2。

## 3. 状态联动与校验

切换 A+ 类型只改变 A+ 模块，不清空主副图多选；排版“每种排版生成一张/无文字模式”互斥；数量和排版共同重算预计产物；主副图与 A+ 可独立展开；修改品牌基因后新草稿标记 dirty，不能覆盖已生成结果。

通用状态必须落到具体字段：`draft/dirty → validating → submitting → running → succeeded|failed|cancelled`；切换配置不删除已完成任务；重新上传源文件时使旧结果标记为“来自旧版本”，不能冒充当前配置结果。

## 4. 主操作路径

上传商品图→AI 分析并校对商品信息→配置品牌/合规→选择模型品质→配置 A+ 与主副图→核对总张数→开始生成→按组查看/下载/重做/保存资产。

提交按钮旁显示产物数量/预计输出，不显示原站算力。任务提交后锁定本次配置快照；仍允许编辑下一稿。结果支持下载、保存资产、发送到画布（如适用）、单结果重试和查看本次输入快照。

## 5. 失败与恢复

- 上传失败：保留其他输入和配置，定位到失败文件；格式/尺寸/数量错误在控件旁说明，不只弹通用错误。
- 任务失败：保留源资产、全部配置、蒙版/图层/片段等工作数据；允许按相同快照重试或修改后新建任务。
- 部分失败：按结果单元/语言/SKU/片段显示状态，只重试失败单元，已成功结果不重复生成。
- 离开/刷新：保存当前工具草稿和编辑器状态；有未保存画布工作时弹出确认。网络超时进入 `unknown`，先查询任务再决定是否重试，禁止盲目重复提交。

## 6. UI 组件与视觉

组件：`SuiteComposer + ModuleCountEditor + LayoutModeRadio + AssetResultGroups`。面板用 `bg-card`，主区用 `bg-background`，边框 `border-border`，选中 `bg-accent`，主操作 `bg-primary`；正文 14px/22px，控件 36px，主按钮 40px，圆角 8–10px。颜色、字体和焦点环全部取无限画布令牌；不使用 LinkFox 紫色品牌。画布工具必须提供 40×40px 最小点击区、键盘焦点和撤销/重做。

## 7. 技术绑定与数据

- 专用组件：`SuiteComposer + ModuleCountEditor + LayoutModeRadio + AssetResultGroups`；共享 ToolShell 只负责导航、资产选择、任务状态和历史，不吞掉本页专用状态。
- 草稿键：`tool-draft:v1:PRODUCT_IMAGE_SUITE`；任务包含 `toolId + draftRevision + configSnapshot + sourceAssetIds + clientOperationId`。
- 提交前在当前页面执行必填、数量、尺寸、蒙版/位置等校验；服务端按同一 schema 再校验。

| 字段 | 页面控件 | 校验/说明 |
|---|---|---|
| `imageUrl` | Upload/AssetPicker；HTTPS/本地资产 ID，类型/大小由 provider 校验 | string(URL)；required=是（输出/结果字段除外）；HTTPS、上传后资产 ID、签名 URL 15min |
| `outputNum` | InputNumber/Slider；整数，范围由 ToolSpec/provider 目录决定 | integer；required=是；范围取 chunk/模型目录，未加载时禁用；outputNum 默认 1 |

## 8. 本页验收

1. 首屏能看到并操作本页独有区域与控件，不是通用任务卡片；上述全部主流程可实际走通。
2. 逐项验证第 3 节联动；源图替换、Tab 切换、数量/语言/比例变化不会串改无关状态。
3. 上传失败、生成失败、部分失败、刷新恢复均按第 5 节执行；结果与提交快照一致。
4. 1920/1440/1024/768/390px 下无关键控件消失；深色模式、键盘操作和移动端主要流程可用。
