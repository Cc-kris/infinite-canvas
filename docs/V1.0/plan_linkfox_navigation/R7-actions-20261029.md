## 三、过程中发现的产品缺陷（未修，仅记录）

`asset_store` / `canvas_store` 均挂在 zustand persist 上，**多标签间为 last-write-wins**：
在 A 标签点「存入资产 / 发送画布」后，若 B 标签（早前打开的工作区）随后发生任意持久化写入，
会把 A 的新资产/新画布条目覆盖掉（实测：HAND_REPAIR 资产第一次保存后消失、画布项目被旧快照冲掉）。
因此本轮所有回执均在**同一标签点击后 2s 内立即回读**取得；建议后续把 persist 改为按键合并写入
（或使用 BroadcastChannel 做跨标签状态同步），否则用户多开标签会真实丢数据。
