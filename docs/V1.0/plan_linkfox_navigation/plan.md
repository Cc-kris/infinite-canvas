## 风险

1. **39 个真实生成能力不等于页面壳**：后端/provider 未接通者必须显示未接入，验收分层。
2. **原站关系歧义**：在 registry 和文档保留 `origin: original|supplemental`，后续可配置调整。
3. **顶栏空间**：五类菜单 + 原入口在窄屏拥挤；桌面滚动/折叠，移动 Drawer。
4. **原站视觉 vs 无限画布风格**：布局/交互复刻，颜色/圆角/阴影使用无限画布令牌，不复制原站品牌。
5. **签名 URL/版权**：不批量热链商用资产；仅使用现有受控示例。
6. **用户已有工作区改动**：不格式化全仓、不覆盖、不提交无关文件。
