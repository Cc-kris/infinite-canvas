# 字段/控件级 1:1 扫描 — 进展与结论（工作记录）

## 一、采样方法（已修正两轮踩坑）

探针：`.verify-tools/frontend-diff/fieldsprobe.mjs`，输出 `fields-<site>/<ID>.json`（texts / heads / fields{kind,label,ph,opts,sec}）。

**踩坑与修正**

| 坑 | 现象 | 修正 |
|---|---|---|
| 文本提取按换行切分 | texts 恒为 0 | 先归一化空白再切分 |
| 混入左侧栏 | 误报 | 排除导航区 |
| 采样时盲点 `aria-expanded=false` 展开折叠区 | 会点开「从作品库选择」→ 素材库覆盖层，**39 页全部只抓到素材面板**（我的商品/场景参考图/排序/桌面-保温杯） | **禁止任何点击**，两侧统一基础态采样 |

结论：基础态对照才是可信基线。折叠区内容在 DOM 中根本不存在，不可作为缺口判据。

## 二、差异口径

1. 原站条目（归一化去空白/标点）在本地「可见文本 + 字段 label + 选项」中缺失；
2. 该条目在原站出现页数 ≤3（>3 视为全站导航/页脚套壳，剔除）；
3. 剔除 PRD 禁用文案（点数/算力/会员/免费/促销）。

结果：**112 条 / 18 页**；其中本地源码完全搜不到 = 真缺 35 条，源码已有 = 措辞差异 77 条。

## 三、排除项（不算缺口）

- **AI_TEXT / ORNAMENT_TEXT**：原站该 URL 重定向首页，抓到的是首页营销案例块（蓝海扫描专家/VOC洞察专家/利润核算专家…）。PRD §2 这两页只要求 `prompt/fontname/fontSize/left/right`，**不复刻营销块**。
- **IMAGE_TEXT_EDIT**：原站 404（页面不存在），无对照意义。
- 已被 PRD 明确禁止的「点/算力」计费文案。

## 五、验证方式

改完后重跑该页探针（基础态），确认 listed 条目消失：
```bash
cd .verify-tools/frontend-diff && node fieldsprobe.mjs --site local --id <ID>
```
再跑差异脚本，确认该页 真缺 归零。
