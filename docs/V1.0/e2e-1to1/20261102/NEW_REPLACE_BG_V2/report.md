## 结论

原站（`/draw/product-home`「商品图合成」）是**单页模板画廊**：大上传区 + 排序 + 标签搜索 + 16 类目 + 40+ 模板卡（可滚动 2207px）。本地是 4 步纵向工具表单，首屏只能看到上传与抠图，场景/比例/张数/生成被推到 y1290–2228，模板缩到 8 张且丢失排序与搜索。交互可用（本地 6 次点击 5 次有可观测效果），功能层有真实构建/校验/失败映射但无真实调用证据 → **视觉 FAIL / 布局 FAIL / 交互 PASS / 功能 UNVERIFIED**。
