## 结论

LinkFox 公共站没有独立「商品营销素材」页，只有 `product-image-suite?batchType=PRODUCT_MATERIAL`（商品套图的营销变体）。对照结果：原站的「上传卡三按钮可用 + Amazon 类目树 + 商品信息向导 + 品牌基因抽屉 + 单行模型卡 + 主副图/A+ 两个开关 + 固定 400 点价格 + 示例引导空态」在本地被改成「三按钮中两个 disabled + 8 个中文类目 + 品牌/合规 平铺 select + 分辨率/品质 5+3 chip + A+ 与主副图两个常驻配置卡 + 预计 12 张 + 黄色校验横幅 + 无示例空态」；并把 `商品库未接入（PARTIAL）` 这类内部状态写进按钮。交互 10 项有反馈，但顶部同类工具 chip 会导致整页跳走。**视觉 FAIL / 布局 FAIL / 交互 PASS / 功能 UNVERIFIED**。
