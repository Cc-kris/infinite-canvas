## 结论

原站「手持商品」是单列配置（上传 + 图片化姿势选择 + 张数 + 生成@950 可见）+ 结果区示例引导；本地把姿势改成文字胶囊、加了场景类型/检测类型/历史任务，并使**生成按钮掉出首屏（y1004）**、缺少 `从商品库选择`。原站姿势/张数为图形控件，本轮只有 1 次可点证据 → **视觉 FAIL / 布局 FAIL / 交互 本地 PASS · 原站 PARTIAL（证据不足） / 功能 UNVERIFIED**。
