## 功能验收（只读源码）

- `web/src/features/tools/adapters/image-translation.ts:80-90` `createTaskStoreRunPort()` 默认走 `useToolTaskStore.getState().runTool`（真实 TaskGateway）；文件头 `1-12` 注明「图像翻译走共享 TaskGateway，空结果判失败」。
- OCR：同文件 `52-78` 文本/视觉问答端口默认实现 `requestImageQuestion`（取用户当前配置的图像模型，例如 `gpt-image-2`），即本地额外增加的「先 OCR 再逐语言重排」链路——原站无此交互（原站仅整图翻译 + 遮罩不翻译区）。
- 历史任务证据：本地「历史任务 1 条 · 2026-10-29 16:06 · 已完成 · default::gpt-image-2 · image · 1 个结果」。
- 本轮未提交翻译 → 运行期产物未复核。

## 结论

语言清单（原文 11 项、目标 5 组共 52 项）、分组标题、红字提示文案与原站逐字一致，是本案对齐度最高的部分；但结果区被替换为 OCR 矩阵、上传后缺「遮罩不翻译区」、素材库入口禁用、栏宽与主色不同。**不判 PASS。**
