工具主体信息架构（上传→商品信息→品牌合规→模型→生成内容→结果）与 LinkFox 一致，但配置栏宽度、结果区宽度、rail 选项、素材库入口、商品类目控件、向导/品牌/合规三处弹窗形态与本地差异明显，并存在多处本地自造元素（公告条、重复 chip 条、内嵌历史、暴露内部模型名）。**不判 PASS。**
