## 结论

原站「姿势裂变」是一屏完成的小配置（上传 + 姿势库/自定义小 Tab + 张数 + 生成@950），姿势面板按需展开；本地把 12 张姿势卡（含英文 prompt、标签）直接铺进配置栏，导致 scrollHeight 3036、**生成按钮掉到 y2758**，并把 `从作品库选择`/`从商品库选择`/批量入口全部 disabled，另加 imageTags 标签系统。交互本地 5/5 有效，原站 5 次尝试仅 3 次有变化（图片规则/张数不可文本定位）→ **视觉 FAIL / 布局 FAIL / 交互 本地 PASS · 原站 PARTIAL / 功能 UNVERIFIED**。
