## 结论

LinkFox 公共站**没有独立的「上装换料」工作区**（只有 `/draw/clothing-image-suite` 服装套图；`/draw/material-upper-body` 404）。按「套图内换料子能力」对照：原站的「上传卡三按钮 + 商品类目（Amazon 树）+ 商品信息/向导 + 智能品牌基因 + 智能合规检查 + LF智能模型 + 主副图/A+图开关与配置」在本地全部缺失；本地改用自造的「5 步步进条 + 材质目录 8 大类 + 抠图蒙版 + 1-4 张数量 + 本次提交快照 + 2 列结果占位」，并把 `categoryIds/subType` 等字段名与 `chunk 未取证` 之类内部备注写进用户可见文案。交互 10 项均有反馈但步进条不可点。**视觉 FAIL / 布局 FAIL / 交互 PASS / 功能 UNVERIFIED**。
