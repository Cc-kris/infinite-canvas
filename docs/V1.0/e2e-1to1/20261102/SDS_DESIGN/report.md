## 判定

| 维度 | 判定 | 依据 |
|---|---|---|
| 视觉 | FAIL | 有截图与 DOM 取证；但配置栏落到了**左列**、画布预览区被挤成 49px 竖条（差异 1/2，P0），首屏出现竖排断字文本 |
| 布局 | FAIL | 原站是「左画布 791 + 右配置 287 + 右结果 300」三列；本地是「左配置 360 + 右结果/预览 978」两列，且左列同时塞了「配置卡 + 竖排预览」，预览卡实际宽度 40~49px |
| 交互 | PASS | 双端各实测 ≥5 个零成本控件（产品选择器、分类下拉、素材操作图标、Tab、颜色、上传弹窗、撤销/重做、素材名），均有前后差异证据 |
| 功能 | REAL_PROVIDER（引用既有真实证据，本轮未提交） | 适配器 `web/src/features/tools/adapters/sds-design.ts:runSdsDesign` → `gateway.submit` + `waitForResult`；网关直连 `services/api/image.ts`；既有真实上游取证 `docs/V1.0/plan_linkfox_navigation/evidence/real-acceptance/SDS_DESIGN/result.json`（`status: PASS`，`realProviderCall: true`，b64_json 出图，`02-result.png`）；另有 `evidence/real-acceptance/REAL_ACCEPTANCE_SDS.md` |

## 交互实测

原站（未提交生成）：
1. 「产品」卡 → 弹 622×556 popover（分类/最近使用/搜索/4 列商品网格 40 图）。
2. 分类「服饰快反 ⌄」→ 展开 30+ 分类列表（服饰快反 / 儿童服装 / 儿童家居 / 男士服装 / 女士服装 / 鞋帽配饰 / 美国本地直发 / … / 帽子 / 配饰 / 袜子 / 鞋子）。
3. 商品网格点选一格 → 弹层关闭，画布出现叠加素材图层（小猫图），`_productName` 未变。
4. 「素材操作」第 1 枚图标（替换）→ 无弹层、无可见变化（在未选素材时为空操作）。
5. 「优秀案例」Tab → `aria-selected` 切到优秀案例，面板 300×828 内出现 36 张案例图（每张「预览 / 原图」）。
6. 「选择颜色」卡 → 无弹层、无变化（单色板）。
7. 「上传素材」→ 弹 1220×790 modal（四 Tab + 拖拽区 + 格式要求）。

本地（未提交生成）：
1. 颜色 swatch 依次点「黑色」「原色」→ `aria-pressed` 从 黑色→原色 单切，其余变 false。
2. 「素材操作」撤销/重做 → 均 `disabled=true`（无历史时不可点，符合预期）。
3. 「上传素材」→ 弹 760×359 `role=dialog`，四 Tab 与文案与原站一致。
4. 「优秀案例」Tab → `aria-selected`/`text-primary` 从「生成结果」移到「优秀案例」，出现 18 张案例图。
5. 「历史记录」Tab → 高亮移到「历史记录」，主区切到历史列表（「暂无历史记录，生成成功后会自动留档。」）。
6. 上传本地 600×600 测试图 → 产品区变为「已选择商品图，点击可更换」+ 缩略图；「立即生成」仍 disabled（title「至少上传 1 个素材后才能贴合。」）。
7. 「产品」卡点击 → 直接弹系统文件选择器（无商品库弹层），与差异 4 一致。

## 结论

- 原站可访问，双端截图与点击证据齐全。
- P0 是差异 1/2：三列被压成两列，画布预览区宽度塌到 40~49px，首屏出现逐字竖排的断字文本，画布已不可用；这与 page-spec「素材操作画布 + 贴合结果」的核心信息架构冲突。
- 差异 4/5 属功能缺失（商品库弹层未复刻），差异 6 属本地自造（多出 4 个原始素材没有的颜色）。差异 12（上传素材弹窗）复刻质量高，可作正例。
- 交互 PASS（双端 7 个控件）；功能 REAL_PROVIDER 依据既有真实取证 + 源码链路（`runSdsDesign` → `gateway.submit`），本轮未真实提交。
