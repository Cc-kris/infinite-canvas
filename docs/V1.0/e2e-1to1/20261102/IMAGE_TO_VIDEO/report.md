## 功能代码路径与禁用/缺失能力核对

- 提交链：`registry/image-to-video.ts`（`sourceMode: reference|frames|product-link`）→ `adapters/image-to-video.ts` → gateway。`frames` 模式下 `imageInputMode` 映射 provider frames 通道（`adapters/image-to-video.ts:238`），首帧缺失直接抛 `first-frame-missing`（:146）。
- 三模式必填差异（`adapters/image-to-video.ts:539-541`）：参考素材必填 `imageUrl`；首尾帧必填 `sourceImageUrl`；商品链接必填 `productUrl` **且仍需 ≥1 张参考图**。
- **缺失能力**：商品链接不解析。页面与代码均明示「本页不解析商品数据，仅按原样提交并校验格式」；原站提供「分析」按钮做商品信息/卖点抽取。这是本工具最实质的功能缺口（见差异表）。
- 禁用态：「从作品库选择」「从商品库选择」`disabled`；「立即生成」在缺图/缺链接时 `disabled`（基线 disabled，符合预期）。「分析」按钮 disabled。
- 模型选择：「跟随默认模型（sub2::MiniMax-H3）」为默认，另有 MiniMax-H3 / grok-imagine-video / sub2::MiniMax-H3 可选——原站只暴露单一「视频模型」下拉。

- 布局/交互可用：分栏宽度、结果区位置与原站一致，滚动可达，无阻断性缺陷。
