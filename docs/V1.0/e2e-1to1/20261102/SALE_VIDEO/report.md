## 功能代码路径与禁用/缺失能力核对

- 提交链：`registry/sale-video.ts`（`SALE_VIDEO_COUNTRIES/LANGUAGES/RATIOS/RESOLUTIONS/DURATIONS` 常量 + `composeSaleVideoScriptDraft` 本地草稿）→ `adapters/sale-video.ts` → gateway；`hiddenPrompt` 由模板确定性派生，只读审计，不在页面手填（`video.tsx:941` 注释）。
- **「AI帮写」是本地模板**，不是模型结果：代码与 UI 文案都写明「本地模板，可自行修改，也可撤销」——与原站「AI帮写」调用模型生成存在能力差异。
- 禁用态：「从商品库选择」disabled；「立即生成」在缺商品图时 disabled（基线态）。
- 缺失：原站「UGC种草」为入口卡；本地是直接塞进提示词框的模板标签，无可点展开的模板预览。
