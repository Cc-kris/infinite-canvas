## 结论

原站对应页（`/draw/product-scene?type=2`「场景裂变」）与本地「场景裂变链接」不是同一套信息架构：原站是「上传参考图卡 + 背景相似度 + 场景描述 + 生图模型三选 + 尺寸 + 张数 + 吸底生成」，本地是「URL 文本框 + 可选本地上传 + 裂变数量 + 生成」。原站的相似度、场景描述、生图模型、尺寸四个区块在本地完全缺失；本地自造了 URL 输入与「将发起 N 次真实请求」类提示。配置栏高度（494 vs 890）、张数选择器尺寸与默认值、结果区空态、历史记录 Tab 化也都不一致。功能层是真实 provider（有既有真实出图取证），但存在「二次提交挂起」的开放缺陷。**视觉 FAIL / 布局 FAIL / 交互 PASS / 功能 REAL_PROVIDER（本轮未自行提交）**。
