## 仍存在的差异（按类型）

1. **结果区空态缺少「上传商品图 → 生成结果 → 一键做同款」案例轮播卡。** 原站约 20 页在生成结果空态放 958×472 的白卡轮播，本地多为一行文字。涉及：商品套图、服装套图、套图换色、批量翻译、场景裂变、AI穿衣、手持商品、姿势裂变、AI穿戴、图转视频、带货口播、视频复刻、视频编辑、视频翻译、视频拼接、印花提取。需要每页的真实案例图，本地只有部分工具有案例数据。
2. **上传卡缺少「或试试这些」示例缩略图。** 商品套图、服装套图、AI穿衣、手持商品、姿势裂变、AI穿戴、印花提取、局部消除。
3. **画布类页面空态卡片形态不同。** 原站是居中白卡 + 示例前后对比图 + 标题 + 上传按钮；本地多数没有示例图，按钮样式和排布也不同。涉及高清放大、智能扩图、局部重绘、商品精修、色差修复、印花修复、手部修复、商品替换、素材贴合。
4. **结构性不同的页面。**
   - 商品图（`NEW_REPLACE_BG_V2`）：原站是顶部上传区 + 场景参考图照片墙；本地是三栏配置表单。
   - 商品图设计器（`NEW_DESIGNER`）：原站是「上传商品图 + 模板推荐瀑布流」首页；本地直接进编辑器。
   - 图片文字编辑（`IMAGE_TEXT_EDIT`）：原站是全屏设计器（左文字样式、中画布、右画布尺寸）；本地是表单式三栏。
   - 视频拼接：原站是居中引导卡 +「开始创作」；本地是配置表单。
5. **配置列细节。** 批量翻译结果区有两个空的折叠行；商品精修、色差修复、印花修复的配置列分区和原站 Step 顺序不同；高清放大结果区原站是左右两栏对照，本地右侧多一个独立结果列；视频翻译本地常驻一块黄色「未验证翻译」提示（有意保留的诚实提示）。
