# LinkFox 1:1 复刻全量整改方案（前端界面 & 后端/服务层功能）

> **目标与原则**
> 1. **100% 结构与交互对齐 LinkFox**：涵盖全部 **42 个工具页 + 批量生图工作台** 的页面布局、间距、组件形态、弹窗/浮层（Popover/Modal）及生成结果交互。
> 2. **零自造功能**：彻底清理原站不存在的自造控件、自造步骤条、自造校验阻塞流程、自造“输入快照”与静态算力条。
> 3. **配色保持无限画布主题**：颜色、明暗主题沿用当前无限画布风格，不照搬 LinkFox 紫黑配色。
> 4. **真实生成效果闭环**：所有“AI 分析”“AI 帮写”“自动抠图/点选分割”“生成结果流转”均须跑通真实模型或算法链路，并在浏览器实测验证。

### 1.5 各分类页面结构与组件对齐清单

1. **电商套图（8 个）**
   - `PRODUCT_IMAGE_SUITE`：右栏顶部「历史记录」从静态 `<span>` 改为可点击切换的 Tab；结果卡片改为真实比例大图网格。
   - `WHITE_BACKGROUND`（白底图）：重做为原站白底图专属布局（左侧上传与尺寸/边距/背景色配置，右侧白底生成结果画廊）。
   - `IMAGE_REPLICATION`（爆款图复刻）：按原站复刻流程重做左栏（支持链接/长图输入、拆解模块勾选、商品图替换）与右栏结果区。
   - `SCALE_UP`（高清放大）：自定义宽高移回顶部工具条；渲染 `SCALE_UP_QUALITIES` 画质档位；启用左下角「批量高清放大」入口；右栏挂载 `CompareSlider` 前后对比滑杆。
   - `AI_OUTPAINTING`（智能扩图）：去掉中栏重复的 `ToolResult` 和自造表单控件，对齐原站 `画布 | 240px 参数栏 | 300px 结果与历史栏`；左栏画布补齐四边/四角可拖拽扩图手柄与原图缩放拖拽；右栏历史由静态表格改为缩略图卡片列表。
2. **智能修图（9 个）**
   - `BATCH_MATTING`（批量抠图）：脱离占位组件 `LocalPixelWorkspace`，重做为原站批量抠图画廊与背景切换预览结构。
   - `REMOVE_PEN`（消除笔）：脱离 `ToolShell` 双栏，重做为修图家族标准三栏结构（`画布 | 240px 画笔配置栏 | 300px 结果栏`）。
   - `IMAGE_CROP`（智能裁剪）：由双栏改为三栏结构，将自定义宽高与重置操作收归中栏配置区，右栏展示裁剪结果与历史记录。
   - `PRODUCT_REFINE`（商品精修）：在中栏 `240px` 配置区渲染 `PRODUCT_REFINE_STRENGTHS`（轻度/标准/深度精修档位），右栏合并 `CompareSlider` 与结果列表。
3. **批量生图（1 个）**
   - `/tools/batch-generate`（`batch-page.tsx`）：下线当前开发者控制台式的“并发/预检/CSV导出/多行文本表格”，按原站重做为 **电商多商品图 × 多场景/多模特模板矩阵式批量生图工作台**。
4. **商品图设计（19 个）**
   - `NEW_REPLACE_BG_V2`（商品图）：首页模式激活 `最多收藏 / 最多使用 / 最新` 排序点击，补齐「我的商品」区域与「智能推荐」室内/室外标签筛选。
   - `AI_TEXT`（AI 文字设计）：结果四宫格卡片补齐悬停快捷操作（`做同款 / 相似裂变 / 高清放大`）。
   - `ORNAMENT_TEXT`（饰品文字）、`FISSION_LINK`（Listing 裂变）、`MATERIAL_UPPER_BODY`（素材上身预览）：将直接平铺在结果下方的 `ToolTaskHistory` 收归右栏顶部「历史记录」Tab 切换。
   - `AI_POSE_GENERATOR`（AI 姿势生成）：移除左栏底部的 `ToolTaskHistory`，统一放入右栏，并与 `AI_DRESSING_V2` 模特弹窗打通。
   - `IMAGE_TEXT_EDIT`（图片文字编辑）& `NEW_DESIGNER`（商品图设计器）：脱离普通工具双栏壳层，接入全屏 `/designer` 画布编辑器（激活左侧文字、素材、模板、图层与画布缩放工具栏）。
   - `PRODUCT_MARKET_MATERIAL`（商品营销素材）：从套图壳层独立出来，提供营销海报模板分类选择与图文替换工作区。

## 第二部分：后端 / 服务层功能整改方案（API、模型调用、算法与生成管线）

> **架构说明**：遵循项目规范（`AGENTS.md`），本项目所有外部服务请求统一在 `web/src/services/api/tools/` 与 `web/src/features/tools/adapters/` 中由浏览器前端直连 AI 模型接口或本地媒体管线执行。以下“后端功能”指代 **AI 模型调用、图像分割算法、链接抓取解析、音视频合成管线及真实生成闭环**。

### 2.1 视觉理解与大模型辅助能力（替换本地假逻辑）
