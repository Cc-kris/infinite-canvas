# 点击级 E2E 比对（36 工具）

## 目标
按钮、弹窗、抽屉与原站一致。限定在**工具面板内**，不比对 LinkFox 全局壳（导航/积分/个人中心/促销），依据 2026-10-29 用户纠偏。

## 工具链（`.verify-tools/frontend-diff/`）
| 文件 | 作用 |
|---|---|
| `clickprobe.mjs` | 打开某工具页 → 枚举面板内叶子可点元（打 `data-probe` 编号）→ 逐个 reload + 点击 → 抓「新出现的浮层」+「文本增删」→ 存 `click-{site}/{TOOL}.json` |
| `sweep.sh <site> <max>` | 批量跑；`SKIP_DONE=1` 时跳过已有结果 |
| `compare_clicks.py` | 原站 vs 本地比对，输出 `click-report.json` 与控制台摘要 |

判定三类：
- `onlyOrig`：原站有、本地没有的点击入口（**缺按钮**）
- `overlayMissing`：原站点了出弹窗/抽屉，本地点了没反应（**缺弹窗**）
- `interactDiff`：两边都出内容但文案不同（**内容不一致**）

## 安全红线
`clickprobe.mjs` 的 `DENY` 正则跳过：开始生成/立即生成/提交/支付/充值/购买/删除/清空/移除/退出/注销/登录/注册/下载/导出/保存到/发布/分享。文件选择器（`filechooser`）一律取消。

## 踩过的坑（别再踩）
1. **免责声明浮层**：原站首访有遮罩，不关掉会导致所有点击超时。`load()` 里点「我已知晓/同意/关闭」+ `Escape`。
2. **顶部巨型菜单**：曾被当成「点击后弹窗」，全是误报。排除 `header/nav/[class*=nav]` 内的浮层，并且只统计「基线快照里没有的新浮层」。
3. **登录门限**：原站未登录，图库类入口点击弹登录框 → `gate=true`，比对时剔除。
4. **父容器误当按钮**：只枚举叶子候选（内部不再含候选），否则标签会粘连成一长串。
5. **文本匹配不可靠**：必须重载后重新枚举 + `data-probe` 编号定位，不能用文案前缀找元素。
6. **只覆盖首屏**：枚举条件 `y < innerHeight-60`，折叠区/滚动区尚未覆盖，属于已知盲区。
