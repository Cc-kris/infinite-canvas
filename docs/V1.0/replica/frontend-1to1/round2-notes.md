## 验收链路（实测）
1. dev server: http://localhost:3000（已在跑）
2. 抓取：`cd .verify-tools/frontend-diff && node round2-capture.mjs`（Playwright，1920x839，写 local-dom2/*.json）
3. 比对：`python3 round2_spec.py`（复用 spec3.py 的 内容框/归一化/子串命中 逻辑），输出 round2-state.json

## 采集规则（capture_page.js）
- `textEls` **只取叶子元素**（`e.children.length===0`）：图标+文字混排的按钮/span 不会产出文本行。
- 内容框 cb = MAIN（本页 209,57,1694x765），**x<209（左侧栏）与 y>822（视口外）都不计入**。

## 两类"假缺失"
- **A 类：左侧栏/导航文案**（250、图片编辑、局部重绘…、企业功能、我的商品、场景参考图、下架…）位于 x≈61，被 cb 裁掉。
  原站把这些算进了原站清单，本地同样存在但被裁 → 按要求"不动侧栏/导航"，本轮不处理。
- **B 类：图标+文字混排**导致文字不是叶子节点（立即生成、画笔、撤销、重做、重置、大小：…）。
  修法：把文字包成独立 `<span>`，视觉零变化。
